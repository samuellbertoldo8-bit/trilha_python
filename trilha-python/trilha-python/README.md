# 🐍 Trilha de Aprendizagem em Python

Uma trilha progressiva de exercícios de Python, do zero ao intermediário.
Cada nível começa com atividades simples e termina com um **desafio** que junta tudo o que foi aprendido.

Todas as atividades trazem o **enunciado** no topo do arquivo e o **código resolvido** logo abaixo.

## 📚 Níveis

| Nível | Tema | Conteúdo | Atividades |
|---|---|---|---|
| 1 | [Programas Sequenciais](nivel-01-programas-sequenciais) | `print`, `input`, variáveis, tipos e operadores | 16 |
| 2 | [Estruturas de Decisão](nivel-02-estruturas-de-decisao) | `if`, `elif`, `else` e operadores lógicos | 16 |
| 3 | [Estruturas de Repetição](nivel-03-estruturas-de-repeticao) | `for`, `range`, `while`, `break` e `continue` | 16 |
| 4 | [Estruturas de Dados](nivel-04-estruturas-de-dados) | listas, tuplas, dicionários e conjuntos | 25 |
| 5 | [Modularização (Funções)](nivel-05-modularizacao-funcoes) | `def`, parâmetros, `return`, escopo e `lambda` | 16 |

Siga os níveis **na ordem**: cada um usa o que foi aprendido nos anteriores.

## 🚀 Como usar (alunos)

### 1. Crie a sua cópia no GitHub
1. No topo desta página, clique no botão verde **Use this template** → **Create a new repository**.
2. Dê um nome ao repositório (por exemplo, `trilha-python`) e clique em **Create repository**.

Pronto: agora você tem a sua própria cópia, com todos os níveis, no seu GitHub.

### 2. Baixe para o seu computador
```bash
git clone https://github.com/SEU-USUARIO/trilha-python.git
cd trilha-python
```

### 3. Rode uma atividade
```bash
python nivel-01-programas-sequenciais/atividade_01.py
```

### 4. Pratique e envie suas alterações
Estude o código, modifique, crie suas próprias versões e depois envie para o seu GitHub:
```bash
git add .
git commit -m "Pratiquei o nível 1"
git push
```

## 🛠️ Pré-requisitos
- [Python 3](https://www.python.org/downloads/) instalado
- [Git](https://git-scm.com/downloads) instalado
- Uma conta no [GitHub](https://github.com)
